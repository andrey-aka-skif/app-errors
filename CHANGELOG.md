## [Не выпущено]

## [3.2.0] - 2026-08-08

### Исправлено

- Билдер `fromSuperagent` терял `detail` для статуса 500, в отличие от всех
  остальных статусов и от `fromAxios`.
- Билдеры `fromAxios` и `fromSuperagent` выбрасывали `TypeError` на `null`,
  `undefined` и примитивах. Теперь любой непригодный аргумент даёт
  `UnknownError`: билдер вызывается в `catch` и не должен падать сам.
- Классы ошибок не задавали `name` — у всех экземпляров он был равен `Error`.
  Теперь `error.name` совпадает с именем класса и попадает в стектрейс.

### Изменено

- `ERROR_TYPE` заморожен: попытка изменить или дополнить его выбрасывает
  `TypeError`.
- Относительные импорты внутри `src/` дополнены расширением `.js`.
- Удалён недостижимый код в `fromSuperagent`: проверка `hasServerError`
  всегда истинна после проверки на потерю соединения.

### Добавлено

- Тесты билдеров: 74 проверки таблиц статусов, извлечения `details` и веток
  обрыва связи. До этого логика разбора ответов не проверялась вовсе.
- `npm run verify:dist` — дымовая проверка собранного пакета, встроенная в
  CI. Юнит-тесты гоняются по исходникам и не видят того, что со сборкой
  делают бандлер и минификатор.

## [3.1.6] - 2025-12-27

Запись сводит выпуски 3.1.4, 3.1.5 и 3.1.6: все три содержали изменения
только в конфигурации CI/CD и не затрагивали код пакета.

### Изменено

- Параметризованный запуск сборки.
- Переход на PAT вместо автоматического токена репозитория.
- Исправление адресов реестров публикации.

## [3.1.3] - 2025-12-20

### Добавлено

- Добавлен CI/CD workflow для Github и Gitea
- В CI/CD добавлено явное указание npm тега `latest`

### Изменено

- Обновлены конфигурационные файлы проекта
- Версионирование пакетов теперь происходит на основе git тегов в CI/CD workflow

## [3.1.0] - 2025-07-28

### Добавлено

- Типизированная ошибка `CustomError`.
- Юнит-тесты для `CustomError`.
- Документация по ошибке `CustomError` в `README.md`.

## [3.0.0] - 2025-07-28

### Изменено

- Версия 3.0.0-alpha.2 признана стабильной. Функциональных изменений нет.

## 3.0.0-alpha.2 - 2025-07-28

_Версия не помечена тегом, ссылки на сравнение для неё нет._

### Добавлено

- Типизированные ошибки:
  - `BadRequestError`,
  - `ConflictError`,
  - `DisconnectedError`,
  - `ForbiddenError`,
  - `InternalServerError`,
  - `LogicError`,
  - `NotFoundError`,
  - `UnauthorizedError`,
  - `UnknownError`.
- Билдер типизированных ошибок на основе библиотеки `axios`.
- Билдер типизированных ошибок на основе библиотеки `superagent`.
- Документация по кастомным ошибкам в `README.md`

### Изменено

- **BREAKING CHANGE**: Классы ошибок больше не содержат логику парсинга ответов (перенесено в билдеры).
- **BREAKING CHANGE**: Удалена прямая зависимость от конкретных HTTP-библиотек (теперь используются билдеры).
- **BREAKING CHANGE**: Вместо обобщенного класса ошибки добавлен набор типизированных ошибок.

### Удалено

- Устаревшие классы `AppErrorViaAxios` и `AppErrorViaSuperagent` (заменены на билдеры).

## [2.0.0] - 2024-11-06

### Добавлено

- Классы для обработки сетевых ошибок:
  - `AxiosNetworkAppError` (для `axios`).
  - `SuperagentNetworkAppError` (для `superagent` и `OpenAPI Middleware`).
- Класс `LogicAppError` для бизнес-логики приложения.

### Изменено

- **BREAKING CHANGE**: Переход на сборку через `Vite` (вместо Babel).
- Рефакторинг базового класса `AppError` (теперь не содержит логики парсинга).

## [1.0.0] - 2023-09-28

### Добавлено

- Базовый класс `AppError` с парсингом HTTP-ошибок.
- Заглушки для интеграции:
  - `AppErrorViaAxios` (требует реализации).
  - `AppErrorViaSuperagent` (аналогично).
- Первоначальная документация.

# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Не выпущено]

## [2.1.0] - 2026-08-09

### Добавлено

- Корневая точка входа: классы доступны через `@andrey-aka-skif/app-errors` без указания подпути. Прежние подпути (`/error-types`, `/logic`, `/axios`, `/superagent`) продолжают работать
- Класс `AppError` включён в публичные экспорты
- UMD-сборка рядом с ESM
- Тесты классов ошибок, покрытие `src` — 100%
- Дымовая проверка собранного пакета `npm run verify:dist`, привязанная к хуку `postbuild`
- Раздел «Разработка» в Readme: версионирование, публикация, dist-теги, токены

### Изменено

- Ветка помечена архивной: новая функциональность не вносится, поддержка не гарантируется
- Воркфлоу приведены к стандарту репозитория: публикация по событию GitHub Release вместо пуша тега, ручной перезапуск через `workflow_dispatch`, отказ от подстановки `dist` из кэша, встроенный `GITHUB_TOKEN` на GitHub, обновлённые версии экшенов и рантайма
- dist-тег линии сопровождения: `lts_v2` заменён на вычисляемый `v2-lts`
- Сборка переведена с четырёх точек входа и `preserveModules` на единый бандл
- Конфигурация проекта выровнена с актуальной линией; версия в манифесте заменена заглушкой `0.0.0`, источник истины — git-тег

### Исправлено

- `SuperagentNetworkAppError` падал с `TypeError` на строке, числе и прочих примитивах: оператор `in` применялся к непригодному аргументу. Теперь такой аргумент даёт обычную неизвестную ошибку
- Удалены поля `main` и `module`, указывавшие на файлы, которых сборка не создавала

### Удалено

- Метод `SuperagentNetworkAppError.hasServerError` вместе с недостижимой веткой разбора: после проверки на потерю соединения свойство `response` заведомо есть

## [2.0.5] - 2025-12-20

### Добавлено

- Добавлен CI/CD workflow для Github и Gitea
- В CI/CD добавлено явное указание npm тега `lts_v2` чтобы избежать автоматического добавления `latest`

### Изменено

- Обеновлены конфигурационные файлы проекта
- Версионирование пакетов теперь происходит на основе git тегов в CI/CD workflow

## [2.0.0] - 2024-11-06

### Добавлено

- Классы для обработки сетевых ошибок:
  - `AxiosNetworkAppError` (для `axios`).
  - `SuperagentNetworkAppError` (для `superagent` и `OpenAPI Middleware`).
- Класс `LogicAppError` для бизнес-логики приложения.

### Изменено

- **BREAKING CHANGE**: Переход на сборку через `Vite` (вместо Babel).
- Рефакторинг базового класса `AppError` (теперь не содержит логики парсинга).

## [1.0.0] - 2023-09-28

### Добавлено

- Базовый класс `AppError` с парсингом HTTP-ошибок.
- Заглушки для интеграции:
  - `AppErrorViaAxios` (требует реализации).
  - `AppErrorViaSuperagent` (аналогично).
- Первоначальная документация.
